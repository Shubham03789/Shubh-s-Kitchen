# Shubh's Kitchen

## Web Development Workshop Project

Shubh's Kitchen is a workshop-based web development project created to explore and practice different concepts involved in building, connecting, and deploying web applications.

The project was developed as part of a hands-on workshop and was mainly used to understand practical development workflows, database integration, authentication, environment variables, version control, and deployment.

## What I Learned

- Firebase integration
- Firebase Firestore
- Firebase Authentication and Google Sign-In
- Database connectivity and integration
- CockroachDB
- MySQL / Aiven
- Environment variables
- Git and GitHub
- Project deployment using Netlify
- Project deployment using Vercel

## Technologies & Tools

- Firebase
- Firestore
- CockroachDB
- MySQL
- Git
- GitHub
- Netlify
- Vercel

## Project Purpose

The main purpose of this project was to gain practical experience with web development tools and deployment platforms through a hands-on workshop.

This project should be considered a learning/workshop project rather than a complete production application.
